# Games for the TI-84 Evo-T

A collection of colour games for the **TI-84 Evo-T** graphing calculator, written in Python.
Every game is free, has its own page with a full guide, and was tested on a real TI-84 Evo-T.

> **Made with AI:** these games and their guides were created with the help of AI (Claude by Anthropic).

## How to install a game (short version)

1. Open the game's page and download its `.py` file.
2. Connect the calculator to your computer with a USB cable.
3. Open **https://connectevo.ti.com** in **Google Chrome** or **Microsoft Edge**
   (Safari and Firefox do not work with the TI tool).
4. Drag the `.py` file onto the page and choose **RAM**.
5. On the calculator, open the **Python** app and run the game.

## Good to know for all games

- **RAM, not Archive:** the Python app on the Evo-T only shows files that are in **RAM**.
- **RAM gets deleted** when the calculator stays turned off for a while. To keep a game safe,
  store it in **Archive** and move it back to RAM before playing:
  on the **home screen** press **2nd → mem → Mem Management**, find the game and press **enter**.
  (In the Python app, 2nd → mem does nothing.)
- **High scores** are saved in calculator lists, so they stay after you quit.
- **Keys:** the Evo-T doesn't repeat a key while you hold it, so the games are made for **tapping**.

## Requirements

- A **TI-84 Evo-T** calculator
- A USB cable
- A computer with **Chrome** or **Edge**

The games are made for the TI-84 Evo-T. Other TI-84 models are not tested.
